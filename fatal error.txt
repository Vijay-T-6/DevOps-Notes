how to disable user login
user should exist but disable the access

sudo usermod -L username     # Locks the user account
sudo usermod -U username     # Unlocks the user

sudo usermod -s /sbin/nologin username  # Prevents login
sudo usermod -s /bin/bash username  #again provides access
